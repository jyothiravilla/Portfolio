Claude Job
Agent

An always-on job application assistant. It finds entry-level roles at verified companies, builds a truthful tailored resume for each one, fills the application on the company's own site, and then waits. Nothing is submitted until I approve it.

How it works

Four stages, one human checkpoint

It runs on a small Linux server on a daily schedule, so my laptop can stay closed. The agent does the searching and the form-filling. I make the final call.

  1. Discover companies
  2. Find jobs
  3. Fill application
  4. I approve
  5. Submitted

Discover checks that each company is real and uses its official site. Find reads career pages, scores each job against my resume and emails me a summary. Apply fills up to 3 applications, stops on the final page and emails me the answers and a screenshot. Approve is one command from me. Only then does it submit.

Guardrails

Safety enforced by code

Truthful resumes

A script checks every line of each tailored resume against my locked master resume. If anything is invented, no PDF is made.

Review mode by default

The agent never clicks Submit by itself. Only my own command counts as approval.

Untrusted input

Job posts, web pages and emails are treated as data, never as instructions.
